## 🧠 Machine Learning — Completed

Built my foundation in ML by studying the mathematics behind algorithms, understanding how models learn, and practicing implementations.

**Topics explored:**

* Linear and multiple linear regression
* Gradient descent and batch gradient descent
* Logistic regression, sigmoid and binary cross-entropy
* Feature engineering and preprocessing
* Model evaluation and classification metrics
* Support Vector Machines (SVM)
* Decision trees and ensemble learning
* Voting, bagging, Random Forests and boosting
* Bias–variance trade-off

**Approach:** Understand the intuition → derive the mathematics → implement the algorithm → experiment with data.

## 📝 Learning Philosophy

* **Understanding over completion:** Finishing a playlist means nothing if I cannot explain the concepts.
* **Implementation over imitation:** Write code, experiment, debug, and understand why it works.
* **Multiple perspectives:** Learn the same concept from different resources when necessary.
* **Honest progress tracking:** Distinguish between what I understand, what I can implement, and what still needs revision.
* **Consistency over intensity:** Build skills through sustained practice rather than rushing through a roadmap.
